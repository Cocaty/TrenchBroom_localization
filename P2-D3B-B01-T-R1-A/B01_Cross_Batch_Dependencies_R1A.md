## D4 与 D5 的联动关系

- **D4（术语选择）**：推荐“不参与导出”，正式备选“不导出”。只决定 B01 tooltip 中属性名称用哪个中文说法。
- **D5（翻译范围）**：推荐后续独立 Layer 批次同步翻译两条 UI 字符串；备选暂不翻译。只决定界面文案何时/是否译成中文。

### 若 D4=不参与导出 且 D5=同步翻译
- B01 tooltip：`将当前地图导出为 .map 文件。标记为“不参与导出”的图层将被忽略。`
- 图层 UI 两字符串后续译为同一术语（不参与导出 / 切换不参与导出）
- 三处文案术语一致；需在后续批次中逐字复核

### 若 D4=不导出 且 D5=同步翻译
- B01 tooltip：`将当前地图导出为 .map 文件。标记为“不导出”的图层将被忽略。`
- 图层 UI 同步使用“不导出”

### 若 D5=暂时保留英文
- 两条 UI 字符串保持英文，B01 tooltip **也必须保留英文属性名 `Omit From Export`**
- 不得采用 D4 的中文方案并宣称已经全局统一——界面标签与提示会不一致

### 若 D4=中文方案 但 D5=暂不翻译（不一致组合）
- **本记录不自动允许这种组合**：如用户明确选择，须在决策记录中标注“界面英文、tooltip 中文”的临时不一致状态及后续同步计划

## 边界

- 本轮不把 `LayerEditor.cpp:99` / `LayerListBox.cpp:54` 字符串加入 RA-B01 18 条
